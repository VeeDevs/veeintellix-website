# VeeIntellix M3 IT Solutions

A Vite + React + TypeScript web app for service marketing, consultation booking, and AI-assisted project quoting.

## Local development

```sh
npm install
npm run dev
```

The dev server runs on port `8080` by default (configured in `vite.config.ts`).

## Scripts

```sh
npm run dev
npm run build
npm run preview
npm run lint
npm run test
```

## Tech stack

- Vite
- React
- TypeScript
- Tailwind CSS
- Supabase
